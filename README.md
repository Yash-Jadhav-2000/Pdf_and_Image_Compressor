# 📘 PDF & Image Compression Tool

A simple **Streamlit web app** to compress PDF files (by reducing embedded image sizes) and standalone images (JPG/PNG).  
Built for quick file size reduction with options for **compression level** and **grayscale conversion**.  

---

## ✨ Features

- 📄 **PDF Compression**  
  - Reduce embedded image sizes inside PDF files.  
  - Choose compression level (**Low / Medium / High**).  
  - Optional grayscale conversion for smaller file sizes.  
  - Batch upload multiple PDFs and download compressed results as a ZIP.  

- 🖼️ **Image Compression**  
  - Compress standalone images (`.jpg`, `.jpeg`, `.png`).  
  - Choose compression level (**Low / Medium / High**).  
  - Optional grayscale conversion.  
  - Batch upload multiple images and download as a ZIP.  

- 🎨 **Clean Blue-Themed UI** with tabbed layout for **PDF** and **Image** tools.
